Methods · LAB colour space, L channel only

Four ways to correct one plate

Original

Baseline, no correction

Global HE

One histogram mapping for the whole crop

CLAHE

Equalise per tile with a clip limit (2.0, 8×2 tiles): adaptive, contrast-limited

CLAHE + Top/Black-Hat

L + TopHat − BlackHat, structuring element ≈ 2 × stroke width (from our report)

Homomorphic

f = i·r → ln f = ln i + ln r; FFT high-emphasis filter, γL 0.5 (light), γH 1.5 (edges)

Elif Yeşilyurt · Module 2Pizer 1987 · Zuiderveld 1994 · Serra 1982 · Oppenheim 1968

All methods change only the lightness channel, so colours stay. Global equalisation uses one mapping for the whole plate; CLAHE equalises small tiles with a clip limit. Top-Hat and Black-Hat come from our report. Homomorphic filtering takes a logarithm, so illumination and reflectance add up; then, in the Fourier domain, it damps the slow illumination and boosts the edges.
